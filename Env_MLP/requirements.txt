- CARLA 0.9.15, Python 3.11, PyTorch (CUDA 12.x), `tud_rl`, gymnasium, numpy, opencv-python, tensorboard.
- GPU with ≥ ~28 GB VRAM for the default `buffer_length=100000` (replay buffer is VRAM-resident).
  For an 8 GB card, run **eval only** and shrink the buffer (see below).
